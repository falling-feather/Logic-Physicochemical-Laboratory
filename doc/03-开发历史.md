## 1. 当前周期提交

### 1.1 V7.4.14 修复快照租约测试时钟

- **提交日期**：2026-07-15
- **任务编号**：`BE-001`
- **提交标题**：`V7.4.14 修复快照租约测试时钟`
- **具体完成**：为知识快照脚本的 `run_rebuild` 增加内部可选 `now` 参数；同一显式时刻用于默认参考日期和首次租约获取，使租约占用测试不再依赖测试执行当天的墙钟日期。
- **生产边界**：CLI 不新增时钟参数，调用方未注入 `now` 时仍使用 `utc_now()`；租约心跳和正常重建路径保持真实运行时语义，不把测试时钟暴露为生产运维接口。
- **验证证据**：知识快照调度与目标发布 29 项通过；后端全量在可访问系统临时目录的环境中为 381 通过、5 跳过、0 失败；`git diff --check` 通过。
- **关联说明**：[`02-项目规划.md`](02-项目规划.md) 的 `BE-001`。

### 1.2 V7.4.13 收束页面注册与角色路由

- **提交日期**：2026-07-15
- **任务编号**：`FE-001`
- **提交标题**：`V7.4.13 收束页面注册与角色路由`
- **具体完成**：新增只读 `AstraPageRegistry`，统一 19 个主站页面的 galaxy、course/frontier 标签、懒加载脚本和页面级 ready/enter/leave；Router 删除三张重复页面表与 init/destroy 分支链，`main.js` 和 Service Worker 同步核心 fallback/cache 接线。
- **浏览器修正**：为 `[data-app-roles][hidden]` 与 `.page[hidden]` 增加不可被页面 display 规则覆盖的隐藏门禁；Router 离页调用 `ModuleSelector.closeModule(..., { preserveHash: true })`，避免活动实验清理覆盖学生越权回落的 `#student`。
- **验证证据**：156 个受跟踪 JavaScript 文件语法检查及 13 项前端契约通过；桌面验证未登录入口、学生注册/Cookie Session、`#physics/energy-conservation`、学生直达 `#teacher → #student`、`cosmos → datascience` 页面生命周期和 console；390×844 学生端无横向溢出，教师/管理入口 `display:none`。
- **全量回归说明**：后端全量为 375 通过、5 跳过、1 失败、5 环境错误；5 个目标发布用例在沙箱外重跑全部通过，临时目录错误已排除。剩余失败由测试把租约时间固定在 2026-07-13、脚本使用 2026-07-15 当前墙钟导致租约自然过期，已登记 `BE-001`，不将其隐瞒为全绿，也不把它混入本次前端实现。
- **边界**：本版本未迁移 88 个实验的 `_moduleScripts/init/destroy` 分散清单；该部分继续留在 `FE-001`，不将页面注册首片误报为整个前端结构任务完成。目标环境发布仍受 `OPS-001` 外部输入阻塞。
- **关联说明**：[`02-项目规划.md`](02-项目规划.md) 的 `FE-001`、`QA-001` 与 [`08-前端页面实现索引.md`](08-前端页面实现索引.md)。
