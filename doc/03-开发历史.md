### 1.1 V7.4.20 修复首页移动端溢出

- **提交日期**：2026-07-15
- **任务编号**：`UX-002`
- **提交标题**：`V7.4.20 修复首页移动端溢出`
- **问题来源**：QA-003 在精确 390×844 独立观察到 `#home` 路由的 HTML/body 根级 `scrollWidth=491–492`、`clientWidth=390`，约 101–102px 横向溢出；主开发在 V7.4.19 复现时确认活动首页退化为相对定位和可见溢出，使内部装饰层扩张到根滚动面。
- **根因与修复**：首页原有 `.home-page { position: fixed; overflow: hidden; }` 被基础样式中选择器权重更高的 `.page.active` 覆盖，活动首页实际退化为 `position: relative; overflow-x: visible`。新增 `.page.home-page.active`，固定到 `inset: 0` 与 `100dvh`，并在首页边界裁剪极光、星层和轨道动画；`.home-container` 改为 `height: 100%` 跟随父级动态视口，不靠 body 隐藏滚动条伪装通过，也避免移动工具栏下 `vh/dvh` 高度分叉。
- **合同与缓存**：`home-particle-lifecycle-contract` 新增活动首页选择器、fixed/inset/100dvh/overflow 与 home.css 版本接线断言；`index.html`、HTTP fallback、Router、Service Worker 和 cache name 统一为 `20260715v7420HomeViewportClipP1`，首页 CSS 首次从旧 V7.0 查询版本切换到本次精确版本。
- **验证证据**：专项首页、页面注册和实验注册合同通过；真实 Browser 在精确 390×844 验证 HTML/body 均为 `scrollWidth=clientWidth=390`，活动首页边界为 `0..390`、计算样式为 fixed/hidden 且高度 844px；三轮数学页→首页重入均保持单 Canvas、单首页脚本、五颗卫星和相同根边界，卫星真实点击进入数学页。桌面 1280×720 保持固定全屏、首页导航和视觉层可用，两端 console warn/error 与错误层均为 0。
- **独立边界**：装饰层可在首页内部继续保持超出几何边界的动画构图，但不会再贡献根滚动宽度；实验生命周期和 DNA/遗传实现字节不变。QA-006 对本提交独立验收。
- **后续任务**：主开发先以 PM-003/V7.4.21 恢复 09 号现行后端规划追踪；QA-004 完成后顺序执行 QA-005、QA-006，FE-004 顺延至 V7.4.22。
- **关联说明**：[`02-项目规划.md`](02-项目规划.md) 的 `UX-002`、`QA-006`、`FE-004` 与 [`08-前端页面实现索引.md`](08-前端页面实现索引.md)。
