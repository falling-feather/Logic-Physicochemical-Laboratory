## 二、整体教学判断

当前工科实验室已经适合作为“概念预习、课堂引入、复习演示”的可视化平台。高中生最容易受益的是：把抽象概念变成可拖动、可观察的动态图像；教师最容易使用的是：用 1 到 3 分钟快速引出概念，然后切回板书或例题。

当前主要短板也很清楚：部分实验的“视觉反馈”强于“学习反馈”。学生能看见图像变化，但不一定知道自己应该观察什么、如何把观察转成公式、如何判断自己的理解是否正确。建议后续为每个实验补齐三件事：核心问题、即时解释、1 到 3 个小练习。

化学和生物内容总体方向正确，但有几处事实口径不能继续只按旧教材或简化说法处理。建议把“高中教材口径”和“现代/大学教材补充口径”显式分层，不要混在同一句文案里。

## 四、事实核对重点

### 化学

| 问题 | 推荐改法 |
|---|---|
| 平衡常数与勒夏特列原理 | 温度改变会改变 K；浓度/压强扰动改变 Q，使体系移动；催化剂不改变 K 和平衡位置 |
| 原电池离子迁移 | 电子经外电路由阳极到阴极；盐桥/溶液中阳离子向阴极附近迁移、阴离子向阳极附近迁移，以维持电中性 |
| NaHCO3 溶液 pH | HCO3- 同时可电离和水解，不能只用单一强/弱电解质公式；高中可定性说明水解大于电离，溶液弱碱性 |
| 分子间力与氢键 | 氢键是特殊分子间作用力，通常涉及 H-F/O/N 与孤对电子；沸点还受摩尔质量、分子形状、极化率影响 |

### 生物

| 问题 | 推荐改法 |
|---|---|
| 光合作用 G3P | 本轮已按 G3P（三碳糖磷酸/甘油醛-3-磷酸）与 Calvin 循环口径修正，报告保留该项作为事实核对依据 |
| 细胞呼吸 ATP | 本轮已保留高中教材近似 `38 ATP`，并补充现代真核细胞常见约 30-32 ATP 的条件差异 |
| 有丝/减数分裂 | 间期属于细胞周期，不属于有丝分裂本身；减 I 分离同源染色体，减 II 分离姐妹染色单体 |
| 基因突变 | 插入/缺失不是必然移码；只有非 3 的倍数插入/缺失通常导致移码 |
