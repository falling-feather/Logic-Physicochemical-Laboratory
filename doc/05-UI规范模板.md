### 1.2 Canvas 字体规范（v4.0.1+）

所有 Canvas 文字通过全局 `CF` 对象引用字体族（定义在 `config.js` 顶部），禁止硬编码字体名或使用 `var()` CSS 变量（Canvas API 无法解析 CSS 自定义属性）。

```javascript
// ✅ 正确 — 使用 CF 全局对象
ctx.font = '16px ' + CF.sans;
ctx.font = 'bold 18px ' + CF.mono;
ctx.font = `${fs}px ${CF.sans}`;

// ❌ 禁止 — var() 在 Canvas 中不工作
ctx.font = '16px var(--font-sans, sans-serif)';

// ❌ 禁止 — 硬编码字体
ctx.font = '10px "Noto Sans SC", sans-serif';
```

**字体大小基准**（Canvas 2D 绘制）：

| 用途 | 最小尺寸 | 推荐尺寸 | 字重 |
|------|---------|---------|------|
| 标题/模式名 | 20px | 22-24px | bold / 600 |
| 标签/名称 | 16px | 17-18px | normal / 500 |
| 数值/公式 | 15px | 16-18px | normal（mono） |
| 辅助说明 | 14px | 15-16px | normal |
| 微型注释 | 12px | 14px | normal |

**动态字体大小**（响应式）：

```javascript
// 推荐模式：基于画布宽度的线性缩放 + 最小值保护
const fs = Math.max(15, W * 0.016);
ctx.font = `${fs}px ${CF.sans}`;
```

### 1.6 星序角色工作区与教师分区（V7.4.37）

- 页面层级固定为“星序总览 + 工科试验室/代码空间/未来星系三个学习单元 + 按身份出现的角色工作区”。学生、教师、管理员页面不得使用工科试验室品牌、学科 navbar、工科页脚或实验课程壳。
- 桌面角色页使用 `232px` 星序 rail：先列星序总览，再列三个学习单元，最后列当前身份允许的工作区。主内容使用开放分隔线、线性指标和两列工作区，避免 KPI 卡墙、嵌套圆角面板和所有表单同时展开。
- 教师端固定四个分区：`教学总览` 只显示当前身份、班级/课程/待批改/学生摘要、行动队列、教学范围和快速入口；`组织与课程`、`作业发布`、`批改与学情` 承载相应业务。创建学校/班级/课程/单元/作业使用原生 disclosure 按需展开，不得回到整页表单墙。
- 390×844 隐藏桌面 rail，在顶部显示星序面包屑和三个学习单元，在底部固定显示当前角色可用入口；根页面必须清除会让 fixed dock 相对整页定位的 transform `will-change`，并预留底部安全区。
- 深空底色、细轨道、青色操作反馈和低圆角控件沿用 1.4；图标只辅助建立层级，文本标签和可访问名称不可缺失。无数据时以行动建议和空状态替代大面积空卡。

本版已在外部 Edge/Chrome 对桌面教师四分区、管理员星序层级与精确 390×844 教师首屏进行概念—实装对照；QA-009 的“角色工作台信息密度偏高”P3 已由本轮设计纠偏关闭，“星系轨道实装更紧凑”仍是可选视觉优化，不影响当前层级与可用性。

### 1.7 代码空间课程壳（V7.5.4）

- 桌面采用“课程 rail / 当前课程舞台 / 学习方式”三列开放网格；子课和挑战只承载一个目标。390×844 依次排为课程组、当前课程、学习方式或编辑、运行、反馈，禁止把桌面多栏强行压窄。
- 课程列表、子课简报、编辑器与轨迹使用细分隔线和低圆角；青色只标主操作与当前选择，紫色标步骤/课程眉题，完成、警告分别使用薄荷与琥珀。正文和辅助文本必须达到深色背景可读对比度。
- 挑战步骤固定为预测、运行、追踪、修正；公开预检必须写明“仅用于学习反馈”，正式提交不可用时使用禁用控件和真实原因，不用成功色或模拟成绩。
- 页脚继承工科试验室的品牌说明、课程/支持入口、版本/版权三段骨架和移动折叠顺序；允许替换成代码空间文案，但不得恢复不同主题、居中/左对齐混用或实现栈说明。
- V7.5.4 概念—实装对照确认课程主次、细线深空视觉和无卡片墙方向一致；实装减少了概念中的装饰信息密度，并提高 muted 文本透明度以保证真实页面可读性。

### 1.8 未来星系课程壳（V7.5.5）

- 总览使用“课程主张 + 单幅观测主视觉 + 六条开放式航线”建立唯一阅读顺序，不把六方向内容堆成一张长页，也不用圆角卡片矩阵替代目录。桌面航线以编号、课程名、核心问题和三个活动入口横向扫描；390×844 收束为一次展开一个方向的 disclosure。
- 子课固定为“面包屑/目标 → 同课程三活动导航 → 互动观察舞台 + 问题/预测/参数/证据/判断 → 回目录”。桌面观察舞台和判断区允许两列，移动端必须按学习顺序串行，不得把交互控件挤进窄侧栏。
- 深空黑蓝、细分隔线、天青主操作和琥珀当前课程构成未来星系主题；大标题可以具有科技编辑感，但正文、辅助文本和表单标签必须优先保证对比度。生成图只作语境，Canvas/Three 必须响应输入并产生可用于判断的观察结果。
- Three 场景不得持续自转制造“未来感”。减少动效、低性能或无 WebGL 时切换到同任务 Canvas；简化模式必须可见、可操作且不以错误信息吓退学生。
- 页脚使用工科试验室同构的品牌/课程/关于三列和跨列版权行；桌面全部左对齐，移动端按品牌、课程、关于、版权顺序堆叠。课程正文不出现 Three.js、WebGL、Canvas fallback 等实现说明。
- V7.5.5 概念—实装对照已覆盖 1440 目录/轨道子课与精确 390px 目录/简化观测；根宽等于视口，Three 桌面按需加载、减少动效不请求 Three，离页无残留 canvas，console/pageerror/HTTP error 均为 0。

### 1.9 教师课程节奏与代码审阅（V7.5.7）

- `#teacher` 在既有星序 rail 和移动角色 dock 内增加第五个“课程节奏”入口，不为工科试验室、代码空间、未来星系复制三个后台。视图阅读顺序固定为范围选择 → 发布计划 → 学生进度 → 代码提交（仅代码空间）。
- 星系、班级、课程使用一条紧凑 scope bar；发布计划按分块逐行显示顺序、状态、开放时间和前置关系。不得把每个单元包成大圆角卡，也不得把保存、刷新和冲突状态放到视线之外。
- `hidden/locked/open` 既要有文字与可访问名称，也要使用一致的弱红/琥珀/青色线性状态；409 必须在当前编辑区说明“权威版本已更新”，并保留用户重新确认入口，不自动重放写入。
- 学生进度使用可横向理解的矩阵或分块行，列出开始、完成、提交、评分和最近活动；无数据时显示下一步建议，不用空 KPI 卡。代码审阅站采用提交索引 + 只读源码/判题详情双栏，源码使用等宽字体、保留换行并严格转义。
- 384/390px 下 scope 控件、发布行、进度和代码详情按学习管理顺序单列；允许局部表格容器滚动，但页面根宽不得溢出。按钮/选择器至少 44px，焦点可见，固定底部 dock 不遮挡保存或源码末行。
- 学生端 locked 文案只解释“教师按班级节奏开放”，hidden 页面不得泄漏活动标题、稳定键或历史进度；这些状态与教师端颜色/术语一致，但前端显示不替代服务端授权。

## 2. 学科基准模板

### 2.1 数学 — 基准：`FuncProps`（函数性质探究）

**架构特征：**
- Canvas 全宽渲染 + 右侧/底部动态信息面板
- 控件由 JS 动态生成（`_buildControls()`）
- 单一 `draw()` 调用（无 RAF 循环）

**Canvas 配置：**
```javascript
resize() {
    const r = this.wrap.getBoundingClientRect();
    const dpr = devicePixelRatio || 1;
    if (r.width <= 0 || r.height <= 0) return;  // 必须！防止隐藏时触发
    this.W = r.width; this.H = r.height;
    this.canvas.width = this.W * dpr;
    this.canvas.height = this.H * dpr;
    this.ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    this.draw();
}
```

**字体尺寸参考：**
- 坐标轴标签: `17px var(--font-sans)`
- 函数名称: `bold 20px var(--font-sans)`
- 刻度值: `16px var(--font-mono)`
- 标题: `bold 22px var(--font-sans)`

**面板模式：** 单一 `updateInfo()` 方法直接操作已有 DOM 元素

**生命周期：**
```javascript
const FuncProps = {
    init() { /* canvas 创建、事件绑定、ResizeObserver */ },
    destroy() { /* observer.disconnect, removeEventListener, DOM 清理 */ }
};
function initFuncProps() { FuncProps.init(); }
```

### 2.2 物理 — 基准：`Kinematics`（匀变速运动）

**架构特征：**
- Canvas + RAF 动画循环（`performance.now()` dt 驱动）
- HTML 预设 Slider 控件 + JS 绑定
- 分离的信息面板（`kin-info` 数值 + `kin-edu` 教育）

**Canvas 配置：**
```javascript
resize() {
    const rect = this.wrap.getBoundingClientRect();
    const dpr = devicePixelRatio || 1;
    this.W = rect.width; this.H = rect.height;
    this.cvs.width = this.W * dpr;
    this.cvs.height = this.H * dpr;
    this.ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
}
```

**字体尺寸参考：**
- 使用 CSS 变量: `var(--font-mono)`, `var(--font-sans)`
- 标签: `11px var(--font-mono)`（物理标准偏小，因信息密度高）
- 数值: `10px var(--font-mono)`

> **注意**: 物理实验因数据密集，字体尺寸可适当偏小（10-11px），但不应低于 10px。

**面板模式：**
- 预设 HTML 元素: `<div id="kin-info">`, `<div id="kin-edu">`
- JS 中通过 `getElementById` 获取并更新 `innerHTML`

**动画循环模板：**
```javascript
_loop(now) {
    if (!this._running) return;
    const dt = Math.min((now - (this._prev || now)) / 1000, 0.05);
    this._prev = now;
    // 物理更新 + 绘制
    this._raf = requestAnimationFrame(t => this._loop(t));
},
destroy() {
    this._running = false;
    cancelAnimationFrame(this._raf);
}
```

## 3. 通用代码模式

### 3.1 实验模块标准结构

```javascript
const ExperimentName = {
    // === 状态 ===
    canvas: null, ctx: null, W: 0, H: 0,
    _raf: 0, _running: false,
    _ro: null,  // ResizeObserver

    // === 生命周期 ===
    init() {
        const sec = document.getElementById('module-xxx');
        const wrap = sec.querySelector('.canvas-wrap');
        this.canvas = wrap.querySelector('canvas');
        this.ctx = this.canvas.getContext('2d');
        
        this._ro = new ResizeObserver(() => this.resize());
        this._ro.observe(wrap);
        this.wrap = wrap;
        
        this._injectInfoPanel(sec);
        this.resize();
        this._running = true;
        this._loop(performance.now());
    },
    
    destroy() {
        this._running = false;
        cancelAnimationFrame(this._raf);
        this._ro?.disconnect();
        // 移除事件监听、清理 DOM
    },
    
    // === Canvas ===
    resize() {
        const r = this.wrap.getBoundingClientRect();
        const dpr = devicePixelRatio || 1;
        if (r.width <= 0 || r.height <= 0) return;
        this.W = r.width; this.H = r.height;
        this.canvas.width = this.W * dpr;
        this.canvas.height = this.H * dpr;
        this.ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
    },
    
    _loop(now) {
        if (!this._running) return;
        const dt = Math.min((now - (this._prev || now)) / 1000, 0.05);
        this._prev = now;
        this._update(dt);
        this._draw();
        this._raf = requestAnimationFrame(t => this._loop(t));
    },
    
    // === 面板 ===
    _injectInfoPanel(sec) { /* 动态创建教育面板 DOM */ },
    _updateInfo(data) { /* 更新面板内容 */ }
};

function initExperimentName() { ExperimentName.init(); }
```

### 3.2 resize 安全守卫（必须）

```javascript
resize() {
    const r = this.wrap.getBoundingClientRect();
    if (r.width <= 0 || r.height <= 0) return;  // ← 关键！
    // ...
}
```

**原因**：当通过路由切换离开实验页面时，`ResizeObserver` 可能在 section 已隐藏（宽高为 0）时触发回调。如果不做此守卫，可能导致：
- 除以零（`step = range / W` → `Infinity`）
- 无限循环（`for` 循环的 `step=0`）
- 浏览器卡死

### 3.3 destroy 清理清单

```javascript
destroy() {
    // 1. 停止动画
    this._running = false;
    cancelAnimationFrame(this._raf);
    
    // 2. 断开观察器
    this._ro?.disconnect();
    
    // 3. 移除事件监听（必须用具名函数引用）
    this.canvas.removeEventListener('mousemove', this._onMouseMove);
    window.removeEventListener('resize', this._onResize);
    
    // 4. 清理动态注入的 DOM
    this._panel?.remove();
    
    // 5. 重置状态
    this.canvas = null; this.ctx = null;
}
```
