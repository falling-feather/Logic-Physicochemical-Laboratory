## 1. 项目定位

星序 Astra 是面向高中与大学初阶学习者、教师和平台管理员的多星系可视化学习平台。产品以交互实验和知识探索为学习入口，以 FastAPI 业务后端承接账号、组织、课程、作业、内容、学习分析、后台任务与审计治理。

一级产品入口包括：

| 星系 | 定位 | 当前入口 |
| --- | --- | --- |
| 工科试验室 | 数学、物理、化学、算法、生物五大学科与 88 个交互实验 | 主站 SPA |
| 代码空间 | 6 组模块化编程课程、18 个四语言预测/运行/追踪/修正活动 | `codevis/` 独立课程子站 |
| 未来星系 | 6 组跨学科课程、18 个单目标活动、6 个 Canvas 互动与按需 Three.js 代表课 | 主站课程目录与六方向独立子课 |

用户进入星序应用外壳前必须完成账号认证。角色由服务端 Session 权威确定：学生仅进入学习域，教师增加教学管理域，管理员增加全局治理域；前端显示不得替代后端授权。

## 2. 系统组成

```text
浏览器
├── 主站 SPA：index.html + shared/ + pages/
├── 代码空间：codevis/
└── HttpOnly Cookie 会话
          │
          ▼
FastAPI 业务后端：backend/
├── 认证与用户
├── 学校、班级、课程、作业
├── 内容、学习分析与知识快照
├── 告警、后台任务与审计
└── 管理概览与受约束治理
          │
          ▼
SQLite 开发环境 / MySQL 发布环境

静态交付：Node 开发静态服务 / C++ Release 静态服务
公开入口：Caddy 将 /api/* 转发到 FastAPI，其余静态请求转发到静态服务
```

技术路径、准确文件、接口、生命周期、启动和维护方法见 [`01-开发者手册.md`](01-开发者手册.md)。

## 5. 协作入口

当前项目采用“用户 + 主开发总控 + 隔离长期工作组”的 V7.5 对接模式；根 `houduan` 始终由主开发单写集成：

1. 主开发在 [`02-项目规划.md`](02-项目规划.md) 建立任务、分配小版本、控制 Git 写入与集成顺序。
2. 代码空间组、未来星系组和课程平台组只在 02 登记的隔离 worktree 与允许路径写入；QA 组保持独立只读验收，不能由主开发自测替代。
3. 三个写入组与 QA 组只服务 V7.5 和后续 `review` 终验；最终通过后按工作树安全门禁取消置顶、归档并恢复单一对接。
4. 现有 `qianduan` worktree 含未提交成果，当前暂停且禁止清理；详细状态以 [`02-项目规划.md`](02-项目规划.md) 的工作树登记为准。
5. `houduan` 提交标题遵守 `.codex/AGENTS.md`：`Vx.y.z GROUP type(scope): 中文说明（TASK-ID）`；V7.5 终验后创建的 `review` 分支改用 `reN：中文说明`。
