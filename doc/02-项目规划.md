## 5. 验收与风险

- 自动化：`python -m pytest backend`、`npm test`、依赖锁检查、C++ manifest/smoke、`git diff --check` 和文档/项目对接校验。
- 浏览器：桌面与 390×844 检查页面身份、非空首屏、错误层、console、截图和至少一条真实交互。
- 本机交付：`127.0.0.1:9001` 同源静态/API、迁移、健康检查、三角色登录与重复启动/停止。
- 后续发布：MySQL、preflight、smoke、topology、stage gate、端口隔离、服务恢复、独立库恢复和回滚证据继续属于暂缓的 OPS-001。
- 风险：认证语义、未来星系动态课程 DOM 与 Three.js/WebGL 降级、多语言判题隔离、隔离测试数据、依赖漂移、外部通道默认关闭，以及恢复标签被误当成活动开发入口。
- 不做：一次性重写工科试验室 88 个实验、恢复 C++ 业务 API、开放任意 SQL/表编辑、为三星系复制三个后台、持久化敏感学习状态、在本轮配置域名/TLS、让 API 进程直接执行无约束学生代码，或把 AI 助教混入尚未批准的 V7.5 范围。
