## 二、🔮 未来星系构思

星序 Astra 的顶层架构允许"星系"作为可扩展单元持续追加。以下为候选方向，按优先级与可行性排序。**所有新星系上线流程参阅 [开发者手册 §17](01-开发者手册.md#17-新增星系开发指南v60-新增)**。

### 已确认方向

| 星系名 | 代号 | 类型 | 学科切入点 | 备注 |
|--------|------|------|-----------|------|
| **智能星系** | `aigalaxy` | 外链子站 | 神经网络可视化 / 决策树 / KNN / 梯度下降 / 注意力机制 | 用户提出；技术栈差异大（需 TensorFlow.js 或自写矩阵运算） |
| **历史星系** | `historia` | 站内星系 | 中国古代发明 / 世界文明轴 / 重大科学事件时间线 | **最低优先级**：已有独立项目承接，星序内仅保留远期占位；以 Canvas 时间轴 + 地图 + 文物 3D 模型为主 |

### 候选方向（待评审）

| 星系名 | 代号 | 类型 | 切入点 | 价值 |
|--------|------|------|-------|------|
| **宇宙星系** | `cosmos` | 站内星系 | 行星运动 / 黑洞引力透镜 / 哈勃红移 / 星系演化 | 与现有物理「万有引力」实验天然衔接，可复用 Canvas 2D |
| **工程星系** | `engineer` | 站内星系 | 桥梁受力 / 电路 PCB / 机械传动 / 流体管道 | 衔接物理"力学"与未来工科应用，面向高中→大学过渡 |
| **语言星系** | `linguist` | 外链子站 | 词源演化树 / 语法结构图 / 国际音标 / 句法分析 | 文理融合方向，吸引文科取向用户；技术栈偏图形+音频 |
| **数据星系** | `dataverse` | 站内星系 | 数据清洗 / 可视化图表 / 统计推断 / 假设检验 | 数学概率延伸，承接高中统计学；与算法星系互补 |

### 评审维度

- **学科覆盖度**：是否填补人教版课标空白？
- **交互复杂度**：能否复用 Canvas 2D + 现有路由？是否需独立子站？
- **资产成本**：星系图标 / 主色 / 卫星图标的设计与制作成本
- **教学价值**：相对当前 65 实验是否带来不可替代的认知体验

### 3.6 新增学科/星系内容缺口评估（v6.2 新增）

当前工科实验室已经覆盖高中数理化生与基础算法主干，但「星序」作为多星系平台，仍缺少几类能拓宽用户面的学科入口。优先级按教学价值、复用现有 Canvas/DOM 能力、资产成本和与既有内容的衔接度综合排序。

| 优先级 | 缺口方向 | 建议承接 | 首批模块建议 | 说明 |
| ------ | -------- | -------- | ------------ | ---- |
| P0 | **地球与宇宙科学** | `cosmos` / `geoscience` 站内星系 | 行星运动进阶、板块构造、天气锋面、地球磁场、遥感图层 | 可复用物理轨道/场线/流体经验，补足高中地理与宇宙科学入口 |
| P0 | **工程应用** | `engineer` 站内星系 | 桥梁受力、齿轮/连杆、PCB 电路、流体管道、热机效率 | 与物理力学、电磁、流体天然衔接，最适合“工科实验室”延展 |
| P1 | **数据科学与 AI** | `dataverse` + `aigalaxy` | 数据清洗、抽样偏差、假设检验、梯度下降、KNN/决策树、注意力机制 | 数学统计和算法之间的桥梁；可先站内 MVP，复杂 AI 再独立子站 |
| P1 | **信息技术基础** | 代码空间 Phase 3/4 | 编译流程、网络分层、加密哈希、操作系统调度、数据流图 | 代码空间不应只停留在运行追踪，可扩展为信息技术星系 |
| P2 | **材料与微观结构** | 化学扩展或工程星系 | 晶体缺陷、合金相图、半导体能带、聚合物链 | 可与晶体结构、化学键、工程应用共用视觉资产 |
| P2 | **语言/人文可视化** | `linguist` / `historia` | 词源树、句法图、文明时间轴、科学史地图 | 拓宽文科用户面；历史因已有独立项目承接，星序内保持低优先级 |

## 五、目录跳转优化（规划）

### 当前跳转路径

```
首页卫星 → 学科页面 Hero → 模块选择器画廊 → 实验内容
导航栏    →                   ↗
实验卡片  →    ↗
Skip-nav  →    直接跳转主内容区
```

### 优化方案

1. **面包屑导航**：实验页面顶部显示 `首页 > 化学 > 分子结构`
2. **学科内目录**：侧边栏显示当前学科所有实验，可快速跳转
3. **桌面端快捷键**：`Ctrl+1~5` 快速切换学科
4. **搜索功能**：全局搜索实验名/关键词
5. **跨学科推荐**：实验底部推荐关联实验（如 DNA → 遗传学 → 基因突变）
