桶排序 — 算法原理

桶排序（Bucket Sort）是一种分配排序算法：

  1. 1

    分配阶段 — 将待排序数组中的元素根据其值的大小，分配到不同的"桶"中。

  2. 2

    排序阶段 — 对每个非空的桶内的元素进行排序。

  3. 3

    收集阶段 — 按照桶的顺序，依次将每个桶中的元素取出，合并成最终的排序结果。

搜索算法对比 — 四种经典方法

在有序数组中查找目标值的四种策略，复杂度从 O(n) 到 O(log log n)：

  1. L

    线性搜索 O(n) — 逐个比较，最简单但最慢。不要求有序。

  2. B

    二分查找 O(log n) — 每次排除一半，20 个元素最多 5 步。

  3. I

    插值查找 O(log log n) — 根据值的分布估算位置，均匀数据极快。

  4. J

    跳跃查找 O(√n) — 先以 √n 步长跳跃定位区间，再线性扫描。

二叉树遍历 — 四种经典方式

访问二叉树所有节点的四种策略，区别在于根节点的访问时机：

  1. 前

    前序 (NLR) — 根→左→右。用于复制树、前缀表达式。根在第一位。

  2. 中

    中序 (LNR) — 左→根→右。BST 的中序输出即为有序序列！

  3. 后

    后序 (LRN) — 左→右→根。适合删除树、后缀表达式求值。

  4. 层

    层序 (BFS) — 用队列逐层访问。适合求最大宽度、层序打印。

哈希表查找 — O(1) 的秘密

哈希表通过哈希函数将键映射到槽位，实现近乎常数时间的查找：

  1. H

    哈希函数 — hash(key) = key % tableSize，将任意键映射到有限槽位。

  2. C

    冲突处理（链地址法） — 同一槽位的多个元素形成链表，逐个比较。

  3. α

    负载因子 α = n/m — 元素数/槽数。α 越大冲突越多，性能从 O(1) 退化到 O(n)。

学习路径：hash 函数 → 冲突处理 → 负载因子 → 扩容重散列

  1. 1

    先定位槽位：示例使用 hash(key)=key mod m，把键映射到 0 到 m-1 的有限数组。

  2. 2

    再处理冲突：链地址法把同槽键放进链表；线性探测从冲突槽开始向后寻找空位。

  3. 3

    最后看负载：α=n/m 变大时，链会变长、探测路径会变长，通常需要扩容并重新散列。

二叉搜索树 BST 与 AVL 旋转

比较普通 BST 的插入顺序风险与 AVL 自平衡旋转，观察高度、平衡因子和查找路径如何变化

学习路径：有序性 → 更新路径 → 平衡因子 → 局部旋转

  1. 1

    BST 有序性：任一节点左子树的键都更小，右子树的键都更大；因此中序遍历会得到升序序列。

  2. 2

    插入与删除：操作先沿比较路径定位；删除双子节点时常用右子树最小值（中序后继）替换。

  3. 3

    AVL 平衡：每个节点左右子树高度差不超过 1；LL/RR 用单旋，LR/RL 用双旋，旋转不改变中序顺序。

最短路径、生成树等图论过程可视化

图算法 — 最短路径 & 最小生成树

两种经典的贪心图算法，用于加权无向图：

  1. D

    Dijkstra 最短路径 — 从起点出发，每次选距离最小的未确认节点，松弛其邻居的距离估计。保证找到从起点到所有节点的最短路径。

  2. P

    Prim 最小生成树 — 从任意节点开始，每次选一条连接已访问和未访问节点的最小权边，加入生成树。保证总权值最小。

  3. !

    对比关键 — Dijkstra 关注到源的累计距离，Prim 关注单条边的权值。点击节点可更换起点。

最小生成树对比 Prim vs Kruskal

用同一张带权无向图并排比较“从树向外扩张”和“按边权全局扫描”的选边顺序

学习路径：连通全部顶点，同时避开多余环

  1. 1

    最小生成树：在连通无向带权图中，选择连接全部顶点且总权重最小的一组边。

  2. 2

    Prim：从一个顶点开始，每步选连接“已在树中”和“未在树中”顶点的最小权边。

  3. 3

    Kruskal：按边权从小到大检查，只有当边连接两个不同连通分量时才接受。

贪心算法 活动选择与区间调度

比较“最早结束”“最早开始”“最短时长”和“最高权重”四种局部选择，理解贪心算法何时正确、何时会失效

学习路径：局部选择 → 不冲突约束 → 交换论证 → 加权边界

  1. 1

    无权区间调度：目标是在单个教室或机器上选出数量最多的不重叠活动。

  2. 2

    最早结束：按结束时间升序扫描，若当前活动开始时间不早于上一个已选活动结束时间，就接受它。

  3. 3

    交换论证：任意最优解中的第一个活动都可替换为结束最早的活动，且不会减少可选数量。

  4. 4

    边界条件：若活动带权重并要求最大总权重，最早结束贪心不再保证最优，通常需要动态规划。

酶的特性 活化能与反应速率

酶促反应 — 降低活化能，不改变反应方向

酶是生物催化剂，能通过与底物形成特异性结合来降低反应活化能，从而加快反应速率；但酶不会改变反应的自由能变化和平衡位置。

用血糖、体温和反馈回路理解机体如何维持动态平衡

稳态 — 围绕设定点的动态调节

稳态不是绝对不变，而是感受器、调节中枢和效应器通过反馈机制，把体内条件维持在适宜范围内。

  1. 1

    负反馈 — 偏离设定点时启动反向调节，是维持血糖、体温等稳态的主要机制。

  2. 2

    正反馈 — 放大原有变化，常见于分娩、凝血等需要快速完成的过程。

  2. 2

  3. 3
