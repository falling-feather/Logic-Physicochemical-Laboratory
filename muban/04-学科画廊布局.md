# 模板 04 · 学科画廊布局（Module Selector）

> 适用场景：**新增学科** / **新增子站内的"内容模块选择"页面**时复用。承担"学科页 Hero + 模块卡片画廊 + 进入实验视图 + 返回画廊"的完整切换。  
> 现行参考：[shared/js/module-selector.js](../shared/js/module-selector.js) · [shared/css/module-selector.css](../shared/css/module-selector.css)

---

## 1. 双视图状态机

```
gallery（画廊视图）
  ├─ 学科 Hero（标题 + 描述 + 进度条）
  ├─ 模块卡片网格（每张卡 = 1 个实验）
  └─ ⬇ 点击卡片
experiment（实验视图）
  ├─ 顶部「返回画廊」按钮
  ├─ 模块侧栏（可折叠，列出同学科其它实验）
  └─ 实验内容区（.content-section[data-module="xxx"]）
```

## 3. 模块卡片样式

```html
<article class="module-card" data-module="kinematics">
  <div class="module-card__icon"><i data-lucide="move"></i></div>
  <h3 class="module-card__title">运动学</h3>
  <p class="module-card__desc">匀变速直线运动 + 抛体的可交互演示</p>
  <span class="module-card__tag">力学</span>
</article>
```

| 元素 | 关键样式 |
|---|---|
| `.module-card` | `display: flex` 列向、`padding: --space-6`、圆角 `--radius-lg`、hover 提升 + 学科主色边框 |
| `.module-gallery` | `grid` + `repeat(auto-fill, minmax(280px, 1fr))` + `gap: --space-4` |
| `.module-card__icon` | 48×48px 圆形 + 学科色半透明背景 + lucide 图标 |

## 4. 学科主色绑定

```css
/* 每个学科页面顶层覆盖 --subject-accent 即可 */
#page-physics    { --subject-accent: var(--accent-purple); }
#page-chemistry  { --subject-accent: #4ade80; }
#page-algorithms { --subject-accent: #f59e0b; }
#page-biology    { --subject-accent: #14b8a6; }
```

所有 `.module-card`、`.subject-hero .progress-bar__fill`、`.module-sidebar-nav .active` 均消费 `--subject-accent`，**新增学科只需追加一行 CSS**。

---

## 5. JS 协议（ModuleSelector）

```javascript
// shared/js/module-selector.js 暴露的全局接口
ModuleSelector.renderGallery(subjectId);  // 切到画廊视图
ModuleSelector.openExperiment(moduleId);  // 切到实验视图
ModuleSelector.backToGallery(subjectId);  // 返回画廊
```

- 由 `router.js` 在 `onPageEnter(subject)` 中调用 `renderGallery`
- 卡片点击 → `openExperiment` 修改 URL hash 为 `#subject/module`
- 侧栏折叠状态写入 `localStorage('module-sidebar-collapsed')`

---

## 6. 新学科上线流程

1. 在 [shared/js/config.js](../shared/js/config.js) 的 `CONFIG.subjects` 添加元数据（id / label / icon / color）
2. 在 `CONFIG.experiments[newId] = [{ id, label, file }, ...]` 列出实验
3. 在 `index.html` 添加 `<section id="page-newid" class="page">` + 模块 section 占位
4. 添加 `#page-newid { --subject-accent: #YOUR_COLOR; }` 一行 CSS
5. 在 [shared/js/router.js](../shared/js/router.js) 的路由表注册（onPageEnter + onPageLeave）
6. 实验 JS 模块按 `pages/<subject>/<module>.js` 编写，全局对象暴露 `initXxx()`
7. 在 `index.html` 添加 `<script defer src="pages/.../module.js?v=...">` 引用

---

## 7. 复用注意事项

- **不要在画廊视图渲染 canvas**——所有 canvas 应延迟到 `openExperiment` 后再初始化
- 模块卡片**必须**保持 ≥ 280px 最小宽，否则触摸点击区不足
- 侧栏折叠（移动端默认折叠）切勿用 `display:none` 切换——用 `transform: translateX()` 保持过渡动画
- 学科 Hero 高度不超过 `30vh`，避免画廊"被挤到屏幕外"
- 若子站想"无学科 Hero"，把 `.subject-hero` 删除即可，layout 自动占满
