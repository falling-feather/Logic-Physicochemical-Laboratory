# 模板 02 · 多星系顶层导航布局（Planets）

> 适用场景：作为「星序」顶层导航大屏，**承接首页 CTA → 进入"多星系选择"→ 进入某星系展开学科行星**。  
> 现行参考：[pages/planets/planets.js](../pages/planets/planets.js) · [pages/planets/planets.css](../pages/planets/planets.css)

---

## 1. 双层状态机

```
┌──────────────────────────────────┐
│  mode = 'galaxies'  (顶层)       │  ← 多个星系球水平平铺
│   ↓ 点击某个星系                  │
│  mode = 'galaxy'    (子层)       │  ← 进入该星系，学科作为行星环绕
│   ↓ 点击学科行星                  │
│  跳转 hash → 学科模块选择器       │
└──────────────────────────────────┘
```

**外链星系**（如代码空间）配 `externalUrl` → 直接 `window.location.href` 跳转子站，不进入展开模式。

---

## 2. 配置驱动（shared/js/config.js）

```javascript
CONFIG.galaxies = [
  {
    id: 'englab',
    label: '工科实验室',
    tagline: 'ENGINEERING · LAB',
    desc: '数学 · 物理 · 化学 · 算法 · 生物 五大学科 N 个可视化实验',
    color: '#3aa9ff',
    subjects: ['mathematics', 'physics', 'chemistry', 'algorithms', 'biology']
  },
  {
    id: 'codespace',
    label: '代码空间',
    tagline: 'CODE · SPACE',
    desc: 'JS · Python · C/C++ 代码执行追踪与数据结构动画（独立子站）',
    color: '#22ff88',
    subjects: ['codespace-viz'],
    // externalUrl: 'codevis/index.html'   ← 如果作为外链星系，加这一行
  }
];
```

新增星系**只需追加一项**——planets 视图自动按数量水平均匀分布。

## 3. 关键 DOM / Canvas

```html
<section id="page-planets" class="page planets-page" aria-label="多星系导航">
  <canvas id="planets-canvas" class="planets-canvas" role="img" aria-label="星系导航"></canvas>
  <div class="planets-hud">
    <div class="planets-crumbs" id="planets-crumbs"></div>     <!-- 面包屑 -->
    <div class="planets-meta"   id="planets-meta"></div>       <!-- 当前星系/学科元数据 -->
  </div>
</section>
```

Planets 完全用 Canvas 2D 渲染（手写正交/透视投影、自转、入场补间），DOM 仅承担 HUD 文字层。

---

## 4. 视觉规范

| 元素 | 数值 |
|---|---|
| 多星系平铺半径 | `r = 1.5`（投影前的归一单位） |
| 单星系内行星环半径 | `r = 1.0` |
| 入场补间时长 | 1400ms（多星系） / 900ms（进入子星系） |
| 默认 pitch（俯仰） | `-0.15` rad |
| 自转角速度 | `0.0015 rad / 帧`（启用 autoRotate 时） |
| 镜空星系球 | 双层球（外壳粒子 + 内核渐变），无实心 |

**减动偏好**：`prefers-reduced-motion: reduce` 时关闭自转与入场补间，仅保留静态投影。

---

## 5. 面包屑约定

```
多星系  >  工科实验室  >  物理
                              ^ 当前所在子页面
```

- `data-action="back-to-galaxies"` → 返回顶层
- `data-action="back-to-galaxy"`   → 返回当前星系（清除学科选择）
- 不渲染当前层节点（已是当前位置无须点击）

---

## 6. 新星系上线流程

1. 在 `CONFIG.galaxies` 追加新条目（参考第 2 节）
2. 若是**站内星系**：注册其子学科到 `CONFIG.experiments[subjectId]`
3. 若是**外链子站**：加 `externalUrl: 'newsite/index.html'`，无需创建 subjects 学科
4. 在 [shared/js/config.js](../shared/js/config.js) 的 `subjectColors` / 元数据中补色（外链星系仅用 `color` 字段即可）
5. 无需改动 planets.js / planets.css —— 整套布局自动适配 N 个星系

---

## 7. 复用注意事项

- **不要破坏** Canvas 内的"投影 → 排序 → 绘制"管线（深度排序基于 z 坐标）
- 行星数量 > 8 时，建议把 r 增大或改为多环——目前算法未做拥挤检测
- 移动端：Canvas 占满视口；HUD 字号经 `clamp()` 控制，禁勿写死 px
