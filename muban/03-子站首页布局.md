## 2. CSS 关键令牌（命名空间隔离）

| 变量 | 用途 |
|---|---|
| `--cv-cyan` / `--cv-cyan-ghost` | 主强调色（赛博震荡青）+ 半透明 ghost 版 |
| `--cv-border-strong` | 卡片/标签边框 |
| `--cv-text-secondary` | 副标题 / 卡片描述 |
| `--cv-font-mono` | 标签 / 代码块字体 |

**子站统一前缀**：CSS 类 `cv-`、JS 全局 `Cv*`（如 `CvRouter`、`CvHome`）。新子站建议换前缀避免命名冲突（如 `as-` / `As*`）。

## 3. 渐变标题（品牌识别符）

```css
.cv-home-hero__title {
    background: linear-gradient(120deg, #e6f4ff 0%, #00d4ff 60%, #a78bfa 100%);
    -webkit-background-clip: text;
    background-clip: text;
    -webkit-text-fill-color: transparent;
    letter-spacing: -0.02em;
}
```

3 段渐变（白光 → 主色 → 紫色提示），**fallback** 必须设：
```css
@supports not (-webkit-background-clip: text) {
  .cv-home-hero__title { color: var(--cv-cyan); }
}
```

## 4. 特性卡片网格

```css
.cv-feature-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 18px;
}
```

`auto-fit + minmax(260, 1fr)` 实现"卡片数量自适应屏宽"——4 卡桌面 / 2 卡平板 / 1 卡手机自动切换，无需 media query。

## 5. Hero CTA 按钮规范

| 类名 | 用途 | 外观 |
|---|---|---|
| `cv-btn cv-btn--primary` | 主行动（"开始追踪"） | 实心主色 + 微发光 |
| `cv-btn cv-btn--ghost`   | 次要行动（"返回 / 文档"） | 透明描边 |
| `cv-btn cv-btn--lg`      | Hero 区域加大版（可选） | 增加 padding |

## 6. 背景动画选项

| 风格 | 推荐子站 | 实现 |
|---|---|---|
| 代码雨（Matrix 风） | 代码空间 / 算法子站 | Canvas 2D，每帧绘制掉落的字符 |
| 粒子网络 | 通用 / 工科主站 | Canvas 2D，节点间近距连线 |
| 几何线条流 | 数学子站 | SVG 或 Canvas，sin/cos 波形 |
| 静态星空 | 任何减动场景 | DOM 三层 + CSS animation |

⚠️ Hero canvas `opacity ≤ 0.7`，避免与前景文字争夺视觉焦点。

---

## 7. 复用注意事项

- 子站**必须**独立 `index.html` + 独立 router（hash 路由也行），不要混入主站 SPA
- CSS / JS 命名空间前缀**强制隔离**，避免与主站 `.btn` / `Router` 等冲突
- 子站 navbar 不要复用主站 navbar 组件——可见品牌一律换成子站自己的
- 子站 footer 提供"返回多星系"链接 → `../index.html#planets`
- 子站如要被 sw.js 缓存，需在 `sw.js` 的 `precache` 数组里追加子站资源路径
