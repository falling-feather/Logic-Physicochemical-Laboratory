## 2. 视觉层级（z-index 约定）

| 层 | 元素 | z-index |
|---|---|---|
| 0 | `.nebula-container`（远景尘带） | 0 |
| 1 | `.hex-grid-overlay`（星图网格） | 1 |
| 2 | `.stars-background`（三层星点） | 2 |
| 3 | `.particle-network`（canvas 连线） | 3 |
| 4 | `.shooting-stars`（低频流星） | 4 |
| 5 | `.home-container`（品牌核心 + 学科节点 + CTA） | 10 |
| 6 | `.hud-frame`（HUD 边角 + 少量数据） | 25 |

## 3. JavaScript 启动钩子（分阶段初始化）

```javascript
// pages/home/home.js 模式
function initHome() {
  initHudData();          // HUD 数据矩阵注入
  initStars();            // 静态星点 DOM
  initParticleNetwork();  // canvas + rAF
  initShootingStars();    // 间歇生成流星
  initTypewriter();       // tagline 循环打字
  initEyeTracking();      // 主星眼睛跟随鼠标
  initSatelliteSystem();  // 品牌核心周围的学科行星轨道
}
```

**性能要点**：粒子数量 ≤ 60、连线阈值 120px、`requestAnimationFrame` 单循环；移动端进一步降到 ≤ 30 并关闭流星。

## 4. CSS 设计令牌依赖

```
shared/css/tokens.css 必备变量：
  --accent-blue · --accent-cyan · --accent-purple
  --bg-deep · --surface-1
  --text-primary · --text-secondary · --text-tertiary
  --space-1..12 · --radius-* · --font-mono
```

新星系若用不同主色，**仅覆盖 `--accent-*` 即可**，星空骨架自动适配。

---

## 5. 复用注意事项

- **可改**：品牌核心颜色（`.star-body` 渐变）、标题文字、打字机内容、HUD 数据条目、行星数量、轨道半径与漂移节奏
- **不要改**：DOM 文本/导航仍归 DOM，Canvas 不承担按钮、标签、长说明
- **必须保留**：`@media (prefers-reduced-motion: reduce)` 降级——把所有 `animation` 缩为 0s 或换静态背景
- **不要在 home 区域放复杂业务交互**：home 只承担"品牌入场 + 学科导航"，业务进入子页面后再渲染
- **眼睛系统只用于 L1 星系首页**：`#home` 可保留主星眼睛与鼠标跟随；L0 `#planets` 顶层入口保持克制星图/HUD，不复用拟人化主星

---

## 6. 新星系如何换装

1. 复制本骨架到 `index.html`
2. 把 `工科实验室` 替换为你的星系名，并用 `.star-subtitle` 标明实验数量或星系定位
3. 在 `pages/home/home.js` 的 `SatelliteSystem.orbits` 中调整子学科行星轨道、深度与漂移节奏
4. 在 `shared/js/config.js` 的 `galaxies` 数组中追加一项
5. 主色用 CSS variable 覆盖即可，避免重写 `.star-*` 类
