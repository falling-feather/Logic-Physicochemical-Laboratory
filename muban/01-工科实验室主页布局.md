## 2. 视觉层级（z-index 约定）

| 层 | 元素 | z-index |
|---|---|---|
| 0 | `.stars-background`（三层星点） | 1 |
| 1 | `.nebula-container`（星云模糊光斑） | 2 |
| 2 | `.particle-network`（canvas 连线） | 3 |
| 3 | `.hex-grid-overlay`（蜂窝栅格） | 4 |
| 4 | `.shooting-stars`（流星粒子） | 5 |
| 5 | `.hud-frame`（HUD 边角 + 扫描线 + 数据） | 6 |
| 6 | `.home-container`（主星 + 文字 + CTA） | 10 |

## 3. JavaScript 启动钩子（分阶段初始化）

```javascript
// pages/home/home.js 模式
function initHome() {
  initHudData();          // HUD 数据矩阵注入
  initStars();            // 静态星点 DOM
  initParticleNetwork();  // canvas + rAF
  initShootingStars();    // 间歇生成流星
  initStarEyes();         // 鼠标追踪
  initTypewriter();       // tagline 循环打字
  initSatelliteSystem();  // 主星周围的学科卫星
}
```

**性能要点**：粒子数量 ≤ 60、连线阈值 120px、`requestAnimationFrame` 单循环；移动端进一步降到 ≤ 30 并关闭流星。

## 4. CSS 设计令牌依赖

```
shared/css/tokens.css 必备变量：
  --accent-blue · --accent-cyan · --accent-purple
  --bg-deep · --surface-1
  --text-primary · --text-secondary · --text-tertiary
  --space-1..12 · --radius-* · --font-mono
```

新星系若用不同主色，**仅覆盖 `--accent-*` 即可**，星空骨架自动适配。

---

## 5. 复用注意事项

- **可改**：主星颜色（`.star-body` 渐变）、标题文字、打字机内容、HUD 数据条目、卫星数量与轨道半径
- **不要改**：三层星空的 `transform-style: preserve-3d` + 各自 `animation` 时长（移除会破坏视差）
- **必须保留**：`@media (prefers-reduced-motion: reduce)` 降级——把所有 `animation` 缩为 0s 或换静态背景
- **不要在 home 区域放复杂业务交互**：home 只承担"品牌入场 + 导航 CTA"，业务进入子页面后再渲染

---

## 6. 新星系如何换装

1. 复制本骨架到 `index.html`
2. 把 `星序` 替换为你的星系名
3. 在 `pages/home/home.js` 的 `initSatelliteSystem()` 中改为你的子学科条目（id / label / color）
4. 在 `shared/js/config.js` 的 `galaxies` 数组中追加一项
5. 主色用 CSS variable 覆盖即可，避免重写 `.star-*` 类
